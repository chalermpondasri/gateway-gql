GraphQL service gateway

## Installation

```bash
$ npm install
```

## Setting up
set process env to target environment such as `development` or `production`  

create `.env.NODE_ENV` file for local testing, for example  
`.env.development`

## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```
